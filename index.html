01 — About

Who am I?

I'm an Android developer who ships. Not prototypes — apps that live on the Play Store, take real traffic, and get updated when users complain.

I work in Kotlin and Java, structure apps around MVVM, and use Room for local storage and Retrofit for everything over the wire. Firebase handles the rest: Remote Config for shipping changes without a release, Crashlytics for finding what broke, Cloud Messaging for bringing people back.

Monetization is part of the job, so I've integrated AdMob, AppLovin and Unity Ads — placed carefully enough to earn without driving people to uninstall. Lately I've been moving my UI work over to Jetpack Compose.

02 — What I do

Where I'm useful

Android app development

Building responsive apps from an empty project and taking over existing codebases without breaking them. Kotlin first, Java where the codebase asks for it.

MVVM & Room

Apps structured so features can be added without rewriting screens. Room for local persistence, plus MVC and MVP on legacy projects that already use them.

Performance & stability

Faster cold starts, smoother lists, fewer ANRs. I chase crashes through Crashlytics and log analysis until the rate actually drops.

Ad network integration

AdMob, AppLovin and Unity Ads, with placement tuned for revenue that doesn't cost retention. Waterfalls, formats, frequency capping.

REST API integration

Retrofit and OkHttp, coroutines and Flow, sensible error and offline states so a dropped connection isn't a blank screen.

Firebase & push messaging

Cloud Messaging and Remote Config wired up to drive engagement without shipping a new release for every change. Firebase Functions for backend logic, Firebase Hosting for the surrounding web pieces.

Google Play Billing

Subscriptions, one-time products and consumables wired through the Play Billing Library, with purchase verification and entitlement state that survives refunds and restores.
